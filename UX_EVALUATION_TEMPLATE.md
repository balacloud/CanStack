# CanStack UX Evaluation Template

Use this template to evaluate the current CanStack experience in a structured way before making major product, design, or positioning changes.

## Scoring System

Score each item:

- `2` = strong
- `1` = acceptable but weak
- `0` = unclear or problematic

Target ranges:

- `30+` = strong direction
- `22-29` = workable but needs refinement
- `0-21` = positioning or UX still unclear

Important:

- [UNVERIFIED] These thresholds are internal decision heuristics, not industry-standard benchmarks.
- Use them for consistency, not false precision.

## Decision Rule

- If score is below `22`, do not add more features yet.
- If score is `22-29`, refine messaging and entry flow before deeper product expansion.
- If score is `30+`, proceed with workflow deepening and persistence improvements.
